# Daniel · Danyw24

Offensive security with a focus on **AI / LLM systems**. I research how agentic setups break —
Model Context Protocol (MCP) servers, LLM agents, and the tooling around them — through prompt
injection, tool poisoning, and the attack surface that opens once a model can take actions.

Everything I publish is reproducible: a working proof-of-concept, a step-by-step write-up, and
canary-based evidence. Where I reproduce a vulnerability someone else disclosed, I credit the
original reporter and label it as a reproduction — never as my own discovery.
